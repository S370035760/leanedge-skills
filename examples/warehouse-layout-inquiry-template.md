# 仓库/工厂布局咨询：复制这张表，先把需求讲清楚

不用先学CAD。把下面内容复制到站内私信或微信，按已有资料填写；不知道的写“待测”，不要猜。
这张表用于确定概念布局或3D展示的需求，不是施工设计委托书。

## 一分钟先填这4项

- 场地用途：原料仓 / 成品仓 / 包材仓 / 生产车间 / 其他：
- 场地长宽、单位和现有平面图：
- 最头疼的一件事：堆不下 / 找货慢 / 收发拥堵 / 向老板讲不清方案 / 其他：
- 想要的成果：分区与动线概念图 / 已有平面图转3D概念效果 / 先讨论范围：

## 有资料再补这6项

| 项目 | 你填写的内容 | 没有资料怎么办 |
|---|---|---|
| 固定条件 | 墙柱、门窗、净高、必须保留的设施；平面图版本与单位 | 手绘带尺寸也可，未测尺寸标清 |
| 货物条件 | 包装尺寸、重量、储存要求、整托或拆零 | 先提供主要品类，不发客户姓名 |
| 库存条件 | 正常库存、峰值库存、待检、退货、呆滞品 | 标明记录日期和计量单位 |
| 作业条件 | 进出货量、扎堆时段、订单行数、领料方式 | 先描述典型一天，不编统计 |
| 搬运条件 | 手推车、地牛、叉车等型号及操作要求 | 不用通用通道数字替代现场核实 |
| 改善约束 | 不能挪的设备、可调整范围、使用目的 | 不知道的先列为要确认的问题 |

## 发图前检查

1. 你有权使用和分享这张图。
2. 遮住地址、联系人、客户名称等非必要信息。
3. 尺寸单位、入口位置、图纸版本可以辨认。
4. 客户图纸只通过约定的私信渠道提交，**不要贴在公开Issue或仓库中**。
