## 先问流程，别急着追求漂亮效果

本演示的顺序是：**原料暂存 → 清洗预处理 → 切配加工 → 包装检测 → 成品冷藏**。

| 区域 | 图上讨论什么 | 下决定前要补什么 |
| --- | --- | --- |
| 原料暂存 | 原料入口与暂存位置 | 到货批次、周转量、包装物和废弃物路线 |
| 清洗预处理 | 清洗与去皮设备的前后关系 | 水、电、排水、操作面、卫生分区 |
| 切配加工 | 输送线与两侧工位关系 | 实际设备尺寸、操作人数、节拍、清洁维护 |
| 包装检测 | 包装和检测的衔接 | 物料补给、待检隔离、不合格品处置 |
| 成品冷藏 | 冷藏与成品出口的衔接 | 储量、周转、温控和装卸条件 |

图中从原料入口进入、从成品出口离开的路线，表达的是物流意图；不代表人员、废弃物和返工路线已经全部校核。看到交叉，就先把问题标在图上，不要用一张效果图掩盖流程问题。

## 同一个方案为什么要看4个视角？

1. **平面图**：核对分区、标注、门的位置和设备前后顺序。
2. **俯视图**：更直观地看区域与设备占位关系。
3. **正向轴测**：讨论输送线、工位与冷藏区的空间关系。
4. **反向轴测**：换个方向检查之前不容易看清的入口和暂存区。

这组空间图适合方案沟通，不是照片级效果展示或扫描重建。设备操作距离、门扇开启、净宽与食品安全、消防、结构和机电条件，都还需要现场复核。
