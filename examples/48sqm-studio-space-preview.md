这是一个 LeanEdge 自有演示，不是客户项目，也不是工厂智能布局助手的输出。它展示的是前期沟通：先看懂平面图里的分区与物件关系，再用空间示意辅助讨论。

## 空间效果示意

![48㎡咖啡工作室概念空间效果示意](https://www.angetlean.com/layout/assets/demo-48sqm-historical-3d.jpg)

示意用于帮助讨论“分区在空间里是什么感觉、家具关系是否直观”。它不是尺寸复核结果，不代表现场测量、施工图或工程设计。

## 看图时重点对照什么

1. 后场与卫生间是否仍在平面图对应的一侧；
2. 吧台、固定长凳与四张圆桌的相对关系是否便于理解；
3. 入口、采光窗和主要活动区是否在示意中保留了可辨认的位置；
4. 哪些具体尺寸、门窗、结构和通行要求仍需现场人员测量核实。

## 想自己试一次，先准备这 5 项

- 原始平面图，以及你有权使用的图纸；
- 场地长宽、净高和比例尺；拿不准的尺寸标“待测”；
- 门、窗、柱、固定设施与不可占用区域；
- 家具或设备清单、数量和主要尺寸；
- 这次最想先看清的事：分区关系、摆放思路，还是汇报展示效果。

资料缺失时，不要让工具猜尺寸。先把问题列出来，效果图才更适合拿来讨论。

## 发图咨询：复制这段就能说明需求

先在闲鱼商品内发图咨询，不必先下单。可复制以下内容，把不确定的地方写“待测”：

```text
场地用途：门店 / 办公室 / 仓库 / 车间 / 其他
面积与长宽：
这次想看清什么：整体空间 / 某个区域 / 设备摆放 / 汇报展示
必须保留的门窗、柱与固定设施：
必须出现的家具或设备：
喜欢的风格（可不填）：
希望使用成果的日期：
附件：有权使用的平面图；可选现场照片
```

发图前请遮住不必要的地址、联系方式及其他敏感信息。我们先判断资料是否足够，再确认一次免费概念预览的范围；完整交付内容、价格与时间通过商品内沟通确定。
