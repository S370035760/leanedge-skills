## 先从一个具体场景开始

临时接到新场地任务，不会 CAD 或 3D 建模，难点往往不是“想不到怎么摆”，而是很难快速把分区、设备关系和动线讲清楚。LeanEdge 的两个 Coze 工具分别处理布局思路与空间表达；它们是独立工具，不承诺自动完成从现场测量到施工图的全流程。

## 开始前准备

1. 场地长宽、柱位、门窗和不可移动设施；不确定的尺寸请标“待复核”。
2. 需要的功能区、设备清单、人员与物料进出方向。
3. 本次要解决的问题：新建布局、搬迁扩产、动线讨论，还是把已有平面方案做成空间示意。
4. 说明输出用途：内部讨论、汇报展示或进一步交由专业人员深化。

输入资料越清楚，讨论越有效；工具输出不能替代现场测量、工程设计、消防审查或施工图审核。
